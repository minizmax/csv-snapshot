CSV Snapshot

นำเข้าไฟล์ CSV หรือวางข้อมูลจาก MySQL

ลากไฟล์มาวาง หรือกด Ctrl+V เพื่อวางแถวที่ copy จาก MySQL ด้วย Copy Row (with names) ข้อมูลอ่านในเบราว์เซอร์นี้เท่านั้น ไม่ถูกอัปโหลดไปที่ไหน

วางข้อมูลจาก MySQL

ใน MySQL Workbench เลือกแถวผลลัพธ์ → คลิกขวา → Copy Row → with names แล้ววางที่นี่ ต้องมีบรรทัดชื่อคอลัมน์และข้อมูลอย่างน้อย 1 แถว (วางแบบ CSV หรือ TSV ก็ได้)
